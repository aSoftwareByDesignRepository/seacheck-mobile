# Live App Store captures (optional)

Drop Simulator / device PNGs here as `iphone-69-01.png` … `iphone-69-06.png`
(matching the shot map in `../GRAPHICS.md`), then run:

```bash
npm run appstore:screenshots
```

Until live Simulator captures exist under this folder, the generator frames Play phone
screenshots from `docs/play-store/assets/screenshots/phone-0N-*.png` (prefer live
Android captures via `bash scripts/capture-play-screenshots.sh`).
