1. Geltungsbereich

Software by Design betreibt keine zentrale Cloud für Ihre Törns, Tracks oder GPS-Verläufe. Daten bleiben auf Ihrem Gerät, sofern Sie sie nicht exportieren oder teilen.

2. Daten auf dem Gerät

DatenZweck
GPS-PositionKarte, Instrumente, Ankeralarm, Tracks
Wegpunkte, Törns, TracksPlanung und Protokoll (SQLite)
Schiffsdaten (optional)Notfalltext, Standardnamen
Offline-KartenpaketeKarten ohne Mobilfunk
EinstellungenPräferenzen

Wir laden Törns, Tracks oder dauerhafte Standortverläufe nicht auf Server von Software by Design hoch.

3. Internet & Drittanbieter

Online kann die App Drittanbieter kontaktieren (nicht Software by Design):

DienstÜbermittelte DatenZweck
OpenSeaMap (t1/t2.openseamap.org)Kachel-Anfragen (Gebiet/Zoom; kein Konto)Basiskarte
OpenSeaMap (tiles.openseamap.org)Kachel-AnfragenSeezeichen-Overlay
OpenSeaMap GeoServer (geoserver.openseamap.org, depth.openseamap.org)Optionale WMS-Anfragen bei aktiviertem Tiefen-OverlayInoffizielle GEBCO-/Track-Tiefenbilder (nur online; nicht in Offline-Paketen)
OpenStreetMap Overpass API (z. B. overpass-api.de, overpass.kumi.systems)Nahezu exakte getippte Koordinaten (Breite/Länge) und ein kleiner Suchradius bei Online-Kartenobjekt-SucheOnline-Seezeichen-Suche, wenn der lokale Index nicht reicht

Diese Anfragen können Kartenbereiche verraten, die Sie ansehen (Kachelanfragen), und bei Overpass-Abfragen die ungefähre getippte Position. Kein Konto erforderlich.

Offline: Nach dem Download eines Regionenpakets im WLAN liegen Kacheln und Seezeichendaten für dieses Gebiet auf dem Gerät. Die App kann funktionieren, ohne Ihre GPS-Position an einen Server zu senden.

4. Was wir nicht tun

  • Kein Verkauf personenbezogener Daten
  • Keine Werbungs- oder Analyse-SDKs in der App
  • Kein Profiling aus Navigationsdaten
